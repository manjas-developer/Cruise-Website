Why Cruise Language?

Engineered from the ground up to unify machine learning operations, clean language syntax, and effortless cross-platform execution.

🧮

Native ML Tensors

Perform vector arithmetic, dot products, and matrix operations natively without relying on heavy external syntax overhead.

🌐

Built-in HTTP Engine

Fetch remote API endpoints and post JSON payloads directly with clean, plain-English syntax commands like fetch() and post().

🎨

Cross-Platform UI

Render desktop GUI components with graceful headless fallback handling, making it fully compatible with iPad terminal emulators.

🧠

Scoped Function Memory

Features structured function definitions (define ... end) with dynamic argument binding and clean lexical scoping.

📱

WebAssembly Browser Shell

Powered by WebAssembly, Cruise scripts can be compiled and executed client-side inside any modern web browser.

📄

Dual File Associations

Full CLI interpreter support for both .cru and .crui file extensions out of the box.

Syntax Quick Reference

Master Cruise Language syntax in under 5 minutes.

1. Declaring Functions 

# Define custom function block
define calculate_total(price, tax):
    total = price + tax
    write("Final Amount:")
    write(total)
end

# Invoke function
calculate_total(100, 18)

2. Tensor Mathematics 

# Create scalar or vector tensors
vec1 = tensor([1.0, 2.0, 3.0])
vec2 = tensor([4.0, 5.0, 6.0])

# Perform operations
write(vec1)
write(vec2)

3. Fetching Remote APIs 

# HTTP GET request
response = fetch("https://api.github.com")
write(response)

# HTTP POST request
data = post("https://httpbin.org/post")

4. GUI Rendering 

# Render desktop window components
background("darkslate")
button("Launch Rocket 🚀")

# Repeat execution loop
5 times write("Rendering UI Frame...")
